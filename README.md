# quiz-master-mad1project
🎓 Quiz Master — MAD1 Full-Stack Web Application

Quiz Master is a full-stack authentication-based quiz platform built as part of the MAD1 project.
It provides separate dashboards for Users and Admin, supports multiple quiz topics, real-time quiz timers, scoring, and performance visualization with charts.

🚀 Project Overview

Quiz Master is designed to offer a clean, smooth quiz-taking experience with secure authentication and an analytics-focused dashboard.

👤 User Features

Register / Login with authentication

Access a personal dashboard

Take quizzes on multiple topics created by the admin

Timer-based quiz attempts

Automatic scoring after quiz submission

View performance analytics with charts

Track previous attempts and progress

🛠️ Admin Features

Secure admin login

Create quizzes on any topic

Add, edit, delete quiz questions

View all users’ scores and attempts

Analyze quiz performance via visual charts

Monitor which users scored how much
